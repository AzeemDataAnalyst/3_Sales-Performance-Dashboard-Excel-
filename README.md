# 📊 Sales Performance Dashboard (Excel)

An interactive **Sales Performance Dashboard** built in Microsoft Excel using Pivot Tables, Slicers, and dynamic charts — designed to track sales KPIs, regional performance, product contribution, and monthly trends at a glance.

![Dashboard Preview](Sales_Performance_Dashboar__jpg.png)

## 🚀 Overview

This dashboard converts raw sales transaction data into a clean, decision-ready, single-screen report. It's built for anyone who wants to practice **Excel dashboarding, Pivot Tables, and data visualization** — analysts, students, and business owners alike.

## 🧩 Project Structure

The workbook contains 3 sheets:

| Sheet | Purpose |
|---|---|
| **Long Data** | Raw/source sales transaction data (Date, Region, Product, Orders, Sales, etc.) |
| **Pivot Table** | Backend Pivot Table powering all charts and KPI cards |
| **Dashboard** | Final interactive dashboard with slicers, KPI cards, and charts |

## 📌 Key Features / KPIs

## 📈 Dashboard Components

1. **KPI Cards** – Total Sales, Total Orders, Avg/Max/Min Sales
2. **Region Sales Performance** – Donut chart (East, North, South, West)
3. **Product Sales Contribution** – Horizontal bar chart (Keyboard, Laptop, Monitor, Mouse, Printer)
4. **Monthly Sales Trend** – Line chart (Jan–Dec) with combo trend overlay
5. **Interactive Slicers** – Filter by Year (2023/2024), Region, and Product

## 🛠️ Tools & Techniques Used

- Microsoft Excel Pivot Tables & Pivot Charts
- Slicers for interactive filtering
- Donut Chart, Bar Chart, Line/Combo Chart
- KPI Card design using shapes & cell formatting
- Custom color theme & dashboard layout design

## 📂 How to Use

1. Download `2__Sales_Dachboard.xlsx`
2. Open in Excel (2016 or later recommended for full slicer/chart support)
3. Go to the **Dashboard** sheet
4. Use the **Year / Region / Product slicers** on the left to filter data
5. All KPIs and charts update automatically
